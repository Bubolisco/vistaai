# Apoie o Vista Aí e o Anota Aí

O Vista Aí e o Anota Aí são gratuitos e de código aberto. Foram criados para facilitar a rotina de professores. Se o projeto for útil para você, uma contribuição voluntária ajuda a renovar o domínio, manter o aplicativo disponível e preparar correções e melhorias.

**Apoiar é opcional.** O aplicativo continua gratuito e nenhuma função depende de pagamento.

## Sobre o projeto

O idealizador, SrBubolisco, é um professor que não sabe programação e buscava uma forma rápida, simples e gratuita de registrar os vistos dos alunos. O aplicativo e esta documentação foram desenvolvidos com ajuda de ferramentas de inteligência artificial. As logos dos mascotes também foram feitas com ajuda de IA.

O foco é facilitar a vida de professores. Sugestões, relatos de problemas, ideias e melhorias são bem-vindos, com ou sem contribuição. Não é necessário programar para compartilhar sugestões. [Contribua com ideias ou relate um problema](https://github.com/Bubolisco/vistaai/issues).

O projeto está em fase de desenvolvimento e testes e, até hoje, foi utilizado apenas pelo idealizador.
