# Apoie o Educa Aí

O **Educa Aí** é gratuito e de código aberto. Ele reúne o Vista Aí e o Anota Aí, ferramentas criadas para facilitar a rotina de professores. Se o projeto for útil para você, uma contribuição voluntária ajuda a manter o domínio e preparar correções e melhorias.

**Apoiar é opcional.** O aplicativo continua gratuito e nenhuma função depende de pagamento.
