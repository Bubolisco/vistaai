# Política de segurança

O Vista Aí e o Anota Aí estão em desenvolvimento e ainda não foram validados para uso amplo. Este repositório contém um aplicativo de navegador que armazena dados localmente; não envie dados reais de alunos ao relatar falhas.

## Como relatar

Se encontrar uma falha de segurança, use a opção de relato privado de vulnerabilidade do GitHub, se estiver disponível no repositório. Se não estiver, abra um problema sem incluir dados pessoais, capturas com nomes de estudantes, arquivos de backup, senhas ou códigos QR reais. Peça um canal privado antes de compartilhar detalhes exploráveis.

Inclua apenas:
- navegador e aparelho usados;
- versão do Vista Aí;
- passos de reprodução com dados fictícios;
- impacto observado e uma captura sem dados pessoais, se ajudar.

## Escopo

Esta política cobre o código e os arquivos publicados neste repositório. Os serviços GitHub Pages, Registro.br e Mercado Pago têm seus próprios canais e políticas de segurança.

A proteção local depende do aparelho, do navegador, da senha escolhida e da guarda dos backups. O projeto não oferece contas on-line nem servidor de dados escolares.
